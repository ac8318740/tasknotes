# TaskNotes 4.15.0-fork.5

Fork build of TaskNotes 4.15.0 for BRAT. It includes the fork's earlier changes and these.

## Added

- Task pickers list a recurring task once, even when it has occurrence notes. The row shows how many occurrence notes it has; press Tab or click the count to list them, newest first. Searching for a month or day, such as `2026-06`, also finds them. See [Materialized Occurrence Notes](https://tasknotes.dev/features/recurring-tasks/#materialized-occurrence-notes).
