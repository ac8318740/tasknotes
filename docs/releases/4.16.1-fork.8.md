# TaskNotes 4.16.1-fork.8

Fork build of TaskNotes 4.16.1 for BRAT.

## Fixed

- New time entries on recurring tasks now require an occurrence. If TaskNotes cannot determine one, interactive timers and the time entry editor ask you to choose; cancelling leaves the entry unsaved. API and command-line callers can supply an explicit occurrence date. Editing an entry's clock times keeps its allocation; use **Change occurrence** to move it. The status bar shows the active timer's occurrence. Existing entries keep their recorded occurrence, or lack of one.
