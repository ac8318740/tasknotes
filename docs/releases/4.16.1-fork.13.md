# TaskNotes 4.16.1-fork.13

Fork build of TaskNotes 4.16.1 for BRAT.

## Added

- A task can stop passing values to its subtasks: turn off **Pass values to subtasks** under its subtasks in the edit modal. TaskNotes writes `cascadeToSubtasks: false`, and its subtasks get no priority, contexts or bundle from it or the tasks above it. The task still gets values from its own parents. See [Values Passed to Subtasks](https://tasknotes.dev/features/task-management/#values-passed-to-subtasks) (#2539).
