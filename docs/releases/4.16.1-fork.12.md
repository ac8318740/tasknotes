# TaskNotes 4.16.1-fork.12

Fork build of TaskNotes 4.16.1 for BRAT.

## Added

- Subtasks without their own priority, contexts or bundle setting now get their parent's. TaskNotes copies the values into the subtask and lists them in `inherited`, so Bases can filter on them. The nearest ancestor with its own value wins, edits keep copies current, and editing a copied value makes it the subtask's own. Turn it off with **Pass values to subtasks** under **Settings → TaskNotes → Task Properties**, and run **Apply inherited values to all tasks** to fill in existing subtasks. See [Values Passed to Subtasks](https://tasknotes.dev/features/task-management/#values-passed-to-subtasks).
