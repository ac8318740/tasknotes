# TaskNotes 4.16.1-fork.12

Fork build of TaskNotes 4.16.1 for BRAT.

## Added

- Subtasks without their own priority, contexts or bundle setting now get their parent's and follow its changes. TaskNotes copies the values into the subtask and lists them in `inherited`, so Bases can filter on them. The nearest ancestor with its own value wins, and editing a copied value makes it the subtask's own; clearing it brings the parent's value back. This replaces the **Inherit parent task properties for subtasks** setting, which copied priority and contexts once when a subtask was created. The new **Pass values to subtasks** setting under **Settings → TaskNotes → Task Properties** keeps that setting's value, and **Create subtask** still adds the parent's projects and tags. Run **Apply inherited values to all tasks** to fill in existing subtasks. See [Values Passed to Subtasks](https://tasknotes.dev/features/task-management/#values-passed-to-subtasks).
